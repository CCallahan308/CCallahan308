### What I'm Working On

**[SignalForge](https://github.com/CCallahan308/signalforge)** — Production churn prediction with statistical rigor

This isn't a bootcamp project. I built it to understand how to use statistical methods the right way:
- **Real data** from Kaggle (IBM Telco dataset — 7,043 customers)
- **Statistical rigor**: 5-fold cross-validation, bootstrap confidence intervals, significance testing
- **Business impact**: Found $1.67M annual revenue at risk, 1.21x-1.81x expected ROI
- **Not just "best model"**: Proved Logistic Regression beats Random Forest with statistical significance (p=0.0074)

Why this matters: Most portfolio projects skip the rigor. They use single train/test splits, no confidence intervals, and claim "best model" without evidence. I wanted to do it right.

### My Approach

**I don't just build models. I:**
- Use **real data** (not synthetic toy datasets)
- Add **statistical rigor** (confidence intervals, significance testing)
- Quantify **business impact** (ROI, revenue at risk, cost savings)
- Build for **production** (Docker, APIs, monitoring-ready)

**What I've learned:**
- Feature engineering > algorithm selection (3 hours on features > 10 hours tuning hyperparameters)
- Simple models + good data beat complex models + bad data
- Business metrics matter more than technical metrics
- Statistical rigor isn't optional if you want to be taken seriously
